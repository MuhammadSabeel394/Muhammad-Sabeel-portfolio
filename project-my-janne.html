System Overview & Vision

MY_JANNE is my personal, voice-first AI assistant and autonomous agent ecosystem designed from the ground up for an AI and Data Science student. It coordinates specialized agents, executes authorized desktop and office automation, performs automated exploratory data analysis, generates and tests custom agents, and prepares for future physical robotics control.

"One personal assistant. One central intelligence architecture. Multiple specialized capabilities. One extensible ecosystem."

Problem Statement

Commercial AI assistants exist as cloud-bound conversational bots with no persistent system memory, no multi-step task decomposition, and no ability to safely operate on local data science files, execute statistical analysis, or interface with physical/simulated hardware under verifiable security boundaries.

Engineering Objectives

  • Centralized Orchestration: Construct a deterministic task planner capable of splitting multi-objective user prompts into topological execution graphs.
  • Automated Data Science: Build a specialized DataScienceAgent that performs missing value imputation, outlier detection, and statistical correlation profiling on CSV datasets.
  • AST Code Sandboxing: Implement Abstract Syntax Tree parsing to guarantee generated Python code complies with syntax standards prior to isolated test execution.
  • Voice Pipeline with Zero Cloud Overhead: Integrate push-to-talk audio capture with native Windows SAPI5 TTS text-to-speech for instant, zero-latency feedback.
  • Safety & Robotics Simulation: Develop a 2D kinematic simulation environment with collision monitors and an emergency E-Stop safety layer.
